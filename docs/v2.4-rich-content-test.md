## 2. Mermaid 图表

```mermaid
flowchart LR
  A[Markdown 文档] --> B[解析富内容]
  B --> C{内容类型}
  C -->|mermaid| D[Mermaid SVG]
  C -->|math| E[KaTeX]
  C -->|image| F[图片预览]
```

```mermaid
sequenceDiagram
  participant User as 用户
  participant Editor as 编辑器
  participant Rust as Tauri 命令
  User->>Editor: 打开含图片的笔记
  Editor->>Editor: 尝试 asset:// 加载
  Editor->>Rust: 失败后读取 data URL
  Rust-->>Editor: 返回 base64 图片
  Editor-->>User: 显示图片
```
