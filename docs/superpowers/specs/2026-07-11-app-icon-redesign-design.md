# Margin 应用图标重设计

日期:2026-07-11
状态:已定稿(用户已在草稿轮中选定「丙 · 曲线连接」方案)

## 目标

替换现有应用图标(暗色 squircle + 实心纸张 + 折角 + 金色页边线 + 七条文字线),新图标要求:

- **极简**:全图不超过 3 个颜色,无渐变、无投影、无多余细节。
- **体现笔记/知识库**:图形语义为「页边线 + 相连的旁注节点」——竖干代表页边/正文脊线,三个相连圆点代表知识库中互相链接的笔记。
- **风格参考 VSCode**:纯白底、单一大图形居中、饱满圆润。

## 定稿方案:曲线连接(丙)

### 构图

- 底:纯白 squircle,带一圈极淡的暖灰描边(防止在浅色桌面上「化掉」)。
- 主干:一条粗墨色圆角竖条,居中偏左,即「页边线」。
- 节点:三个实心金色圆点——两个骑在主干上,一个在右侧。
- 连接:两条金色弧线(而非直线)把主干上的节点连向右侧节点,圆头端点,整体柔和圆润。

### 几何规格(1024 × 1024 画布)

沿用现有导出管线的 squircle 几何,`docs/design/APP_ICON.md` 中的导出脚本无需改动:

| 元素 | 规格 |
| --- | --- |
| 画布 | `1024 × 1024 px`,RGBA |
| Squircle | `x=88, y=88, w=848, h=848, rx=190`,填充 `#FFFFFF` |
| 底描边 | 单独矩形内缩 2px:`x=90, y=90, w=844, h=844, rx=188`,描边 `#E7E3D9` 宽 `4`(确保描边完全落在透明裁剪边界内) |
| 墨色主干 | `x=384, y=240, w=56, h=544, rx=28`,填充 `#1E1C17` |
| 上弧线 | `M412 384 C 540 400 600 430 620 512`,描边 `#C79A3B` 宽 `34`,`stroke-linecap="round"` |
| 下弧线 | `M412 640 C 540 624 600 594 620 512`,同上 |
| 节点 × 3 | 圆心 `(412,384)`、`(412,640)`、`(620,512)`,半径 `58`,填充 `#C79A3B` |

绘制顺序:squircle → 两条弧线 → 墨色主干 → 三个圆点(弧线被主干与圆点覆盖端头,视觉上从节点边缘出发)。

### 色板(共 3 色 + 底)

| 用途 | 色值 |
| --- | --- |
| 底 | `#FFFFFF` |
| 底描边 | `#E7E3D9`(暖灰,极淡) |
| 墨(主干) | `#1E1C17` |
| 金(节点/弧线) | `#C79A3B`(品牌金色族,较现图标 `#D8AB4A` 略沉稳,在白底上对比度更好) |

## 交付物

| 文件 | 动作 |
| --- | --- |
| `build/icon-square.svg` | 替换为新图形(规范源) |
| `build/icon.svg` | 同步替换(同一图形) |
| `build/icon.png` | 按 `docs/design/APP_ICON.md` 的 qlmanage + Python 流程重新导出 |
| `src-tauri/icons/icon.png` | 同上流程自动拷贝 |
| `src-tauri/icons/icon.icns` / `icon.ico` | 由新 PNG 重新生成 |
| `docs/design/APP_ICON.md` | 更新「Design Direction」与色板描述,导出流程不变 |

## 验收标准

- 导出 PNG 通过现有校验:`corner_alpha=0 center_alpha=255`。
- 在 macOS Dock(深/浅色桌面)下图形清晰可辨,白底不与浅色背景融为一体。
- 16px 小尺寸下主干与节点仍可分辨(弧线允许视觉上退化为点线相连)。
- 全图无渐变、无投影;颜色数 ≤ 3(不含底描边)。

## 不做的事

- 不改动 Tauri 配置与导出脚本管线。
- 不为深色模式单独出稿(白底图标在深色桌面上天然对比充分)。
- 不引入文字、字母或折角等旧图标元素。
